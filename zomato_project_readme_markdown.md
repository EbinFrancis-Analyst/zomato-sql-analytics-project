# 🍽️ Zomato Sales & Customer Analytics Project

## 📌 Project Overview
This project focuses on analyzing Zomato restaurant, sales, and customer data using SQL and Power BI. The workflow includes database creation, data validation, data cleaning, KPI analysis, business insight generation, and interactive dashboard development.

The project was designed to simulate a real-world business intelligence workflow commonly used in analytics environments.

# 🧹 Data Cleaning & Validation Process
The following validation and cleaning steps were performed before analysis:

- Checked null values
- Validated table relationships
- Verified duplicate records
- Removed invalid sales values
- Standardized rating and cost formats
- Cleaned currency formatting
- Created cleaned analytical tables
